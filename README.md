# 📚 Biblioteca Escolar

Sistema simples de gerenciamento de livros desenvolvido como projeto integrador.

## 🚀 Demonstração

Acesse o projeto online:
https://the-gyro.github.io/Biblioteca-Escolar/

---

## 📌 Funcionalidades

* Cadastro de livros
* Listagem de livros cadastrados
* Interface simples e intuitiva
* Interação dinâmica com JavaScript

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## 📂 Estrutura do projeto

```
/biblioteca
  ├── index.html
  ├── style.css
  └── script.js
```

---

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como parte de um trabalho acadêmico com o objetivo de praticar conceitos básicos de desenvolvimento web, incluindo estruturação de páginas, estilização e manipulação do DOM.
